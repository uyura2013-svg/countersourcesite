COUNTERSOURCE APK HUB

Что внутри:
- парольная админ-панель;
- перетаскивание APK в окно или выбор файла;
- загрузка APK на сервер;
- публичная кнопка скачивания последней сборки.

Запуск:
1. Нужен Node.js 18 или новее.
2. Выполните npm install.
3. Задайте переменные окружения ADMIN_PASSWORD и SESSION_SECRET.
4. Для хостинга с HTTPS задайте NODE_ENV=production.
5. Запустите npm start; приложение слушает PORT (по умолчанию 3000).

Важно:
- Пароль не хранится в HTML; он задаётся на сервере.
- Используйте собственный длинный пароль, не пример из .env.example.
- Нужен Node.js-хостинг с постоянным диском, подключённым к папке uploads.
- Максимальный размер одного APK — 1 ГБ; ограничения хостинга могут быть ниже.
- Публичный файл доступен по адресу /download.
- Публикуйте только файлы, которые вы вправе распространять.
